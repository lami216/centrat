EFC HTML Activation Generator

1. Open efc-license-generator.html in a current Chrome or Edge browser.
2. Paste the EFC device code from the application activation screen.
3. Enter customer/center information and choose perpetual or temporary activation.
4. Select EFC-license-master-private-v3.pem from your own secure storage.
5. Click the generate button. The browser downloads a .efc-license file.

The HTML file works offline. It does not contain the private key and does not upload the selected key anywhere.
The current activation signing key id is efc-license-v3.
Never send EFC-license-master-private-v3.pem to a customer or commit it to GitHub.
